# CRM системного аналитика

Итоговый проект курса «Системный аналитик»: микро-CRM, в которой протокол встречи со стейкхолдером
превращается в задачи для команды, задачи распределяются по сотрудникам, а по итогам считаются качество и KPI.

**Демо:** https://pakmaninlaw.pythonanywhere.com/crm/ (данные общие для всех посетителей и сбрасываются раз в сутки)

## Что умеет

| Требование ТЗ | Как реализовано |
|---|---|
| Модуль фиксации интервью | Вкладка «Интервью»: тема, стейкхолдер, дата, протокол встречи. Архив интервью со ссылками на созданные задачи |
| Голосовой ввод (бета) | Запись с микрофона и распознавание речи в браузере (Web Speech API, Chrome/Edge). Текст попадает в протокол, его можно поправить |
| Генератор задач | Протокол разбивается на тезисы-требования. Каждый тезис → задача с отделом **Frontend / Backend / Architecture / Security**, приоритетом и сроком (срок берётся из текста: «до 15.10», «через 2 недели», «срочно») |
| Учёт сотрудников | Сотрудники с отделом и должностью, статусы «больничный / отпуск» на период |
| Автоназначение | Задача уходит доступному сотруднику нужного отдела с наименьшей загрузкой (отсутствующие пропускаются) |
| Таймер и дедлайны | Старт/пауза учёта времени, план/факт по часам, подсветка просрочек, проверка актуальности |
| Анализ качества ПО | Задача проходит проверку: «принять» или «вернуть на доработку» с описанием бага. Журнал проверок, доля задач, принятых с первого раза |
| KPI | По сотрудникам, отделам и команде: 50% — выполнено в срок, 30% — принято с первого раза, 20% — план/факт по времени, минус 5 баллов за каждую открытую просрочку |
| Хранение данных | SQLite (`crm.db`) вместо JSON-файла; задачи из старой версии (`project_data.json`) переносятся автоматически |

## Процесс

```
Интервью со стейкхолдером ──► Тезисы-требования ──► Задачи по отделам ──► Автоназначение
        (текст / голос)                                                         │
                                                                                ▼
            KPI и качество ◄── Проверка: принято / возврат (баг) ◄── Работа с таймером
```

## Запуск на своём компьютере

1. Установите Python 3.11+ и зависимости: `pip install -r requirements.txt`
2. Запустите: `python main.py` (или двойной щелчок по `run.bat`) — браузер откроется на http://127.0.0.1:5000
3. На вкладке «Сотрудники» нажмите «Заполнить демо-командой», затем «Интервью» → «Вставить пример» → «Разобрать на задачи»

> Путь к папке проекта должен быть латиницей (например, `C:\Projects\CRM`).

Переменные окружения: `CRM_DEMO=1` — демо-режим (пример данных, лимиты, ежедневный сброс), `CRM_DB` — путь к базе.
